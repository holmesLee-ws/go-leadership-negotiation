# go-leadership-negotiation

조직행동·리더십·협상을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 처음 팀을 맡은 사람, 오래 사람을 이끌어 왔지만 체계가 없는 관리자, 협상을 제대로 배워 보고 싶은 사람을 위한 곳입니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도, 근거 표, 튜터의 행동 규칙만 있습니다. 도식과 조사 자료를 조합한 HTML, 협상 준비서·변화관리 계획서 같은 산출물은 대화하면서 튜터와 함께 그 자리에서 만듭니다. 실습은 주로 역할극입니다. 튜터가 팀원, 협상 상대, 노조 대표 역을 맡습니다.

한국의 법·제도(근로기준법의 직장 내 괴롭힘 조항, 근로자참여법의 노사협의회, 노동조합법의 단체교섭 등)를 뼈대로 하고, 글로벌 기준(ILO 협약, EU 지침, 미국·독일·일본·영국 제도)을 비교 축으로 씁니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 공개 리포라 초대 없이 받을 수 있습니다. 터미널에서 `gh auth login`으로 한 번 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-leadership-negotiation
```

**Claude Code**

```bash
cd ~/Desktop/go-leadership-negotiation
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-leadership-negotiation` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 사람을 이끌거나 협상해 본 경험은 어떤지 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고 역할극을 합니다. 튜터가 내 답과 대사를 반영한 HTML을 만들어 가며 함께 되짚습니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「역할극 멈춰」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역 O·L·N]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 알아 둘 것

- **법률 자문이 아닙니다.** 튜터는 법령을 공식 출처로 확인해 인용하지만, 지금 진행 중인 실제 사건(괴롭힘 신고, 징계, 교섭)에 결론을 내리지 않습니다. 실제 결정은 회사의 인사·법무 담당, 공인노무사·변호사, 고용노동부 상담으로 가져가세요.
- **실제 사람 이야기는 가명으로 기록됩니다.** 동료 이름을 말해도 기록에는 「팀원 A」처럼 남습니다. 그래도 민감한 정보(건강, 징계, 급여)는 대화에 넣지 않는 편이 좋습니다.
- 법령은 바뀝니다. 근거 표의 조회일이 오래됐으면 튜터가 세션 중에 현행을 다시 확인합니다.

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도(O 조직행동 · L 리더십 · N 협상 · X 졸업 프로젝트) |
| [curriculum/sources.md](curriculum/sources.md) | 법령·기준·연구 근거 표(URL·조회일) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 산출물. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 산출물을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 민감한 정보는 대화에 넣지 마세요.
